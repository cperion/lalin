# Standalone Exotype + CDEF + CPS Experiment

This experiment demonstrates the PLDI 2014 exotype pattern without a source language or native backend.
Lua is the host stage, runtime-created exotype owners are the type-level values, `cdefschema` provides exact
low-level instance layouts, generated Lua methods are the next-stage code, and LuaJIT can trace that code.

## Stages

```text
runtime schema
  → Record(schema) first-class exotype
  → Array(Record, count) composed exotype
  → lazy __getentries / __getmethod queries
  → generated exact CDEF declarations and specialized methods
  → seal once
  → unboxed cdata instances and direct CPS execution
```

The test reads `x:i64,y:i64,z:i64` after the host starts. It creates a 24-byte record type and then composes
it with `Array(T, 4)` to create a 104-byte type containing four records by value plus one transition counter.
A different one-field schema creates a distinct 8-byte type.

`sum` and `scale` are generated by recursively querying the element exotype. The array implementation fuses
the element operations into direct field expressions and assignments. There is no runtime schema loop, field
name lookup, boxed element, generic method forwarding, or property query.

`run` is a generated CPS edge:

```lua
function(self, factor)
    return scale(self, factor, scaled)
end
```

The generated `scale` ends with `return completed(self)`. Both functions end in LuaJIT bytecode `CALLT`;
the continuations are stable functions captured once when the concrete type is compiled, never per transition.

## Property discipline

The compiler object is the active computation (`self`). It owns the memoized query cache, active query stack,
depth limit, materialization order, generated listings, and requested-method projection. Property functions
receive that compiler as their first argument and can lazily query properties of other exotypes.

Queries are keyed by exotype identity, property, and arguments. Identical queries are evaluated once. A true
recursive query reports its property trace. Only requested methods are generated. Once a CDEF type is sealed,
requesting another method requires constructing another exotype.

## Run

```sh
luajit experiments/exotype_cps/test.lua
luajit -joff experiments/exotype_cps/test.lua
luajit experiments/exotype_cps/bench.lua 1000000
luajit -joff experiments/exotype_cps/bench.lua 100000
```

The benchmark is only a trace probe. The semantic checks, exact sizes, constructor memoization, lazy queries,
composition, fused code generation, sealing, cycle rejection, and CPS `CALLT` shape are asserted by `test.lua`.
