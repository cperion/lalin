# Archived Compiler Model Docs

These documents are historical design notes from the pre-`next/` compiler-model
reconstruction. They preserve useful reasoning about obligations, identity,
spines, facets, worlds, receiver/operation/result boundaries, and behavior
coverage, but they are no longer the authoritative compiler schema.

Authoritative current schema/design:

```text
next/lua/lalin/compiler/schema.lua
next/docs/SCHEMA_REVIEW_SYNTHESIS.md
next/docs/ASDL_NAMED_CONTROL.md
next/docs/VALUES_MACHINES_NAMED_CONTROL.md
```

Do not implement from the archived O/A/B/S/F inventories or the old normalized
schema text. If an archived note conflicts with `next/`, `next/` wins.
